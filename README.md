## 📦 Installation

### Quick Install (Recommended)

**Step 1:** Copy the addon URL below:

```bash
https://hyperstream-addon.dhrubomohiuddinabdulkadir.workers.dev/manifest.json
```

**Step 2:** Open your **Stremio** or **Nuvio** application

**Step 3:** Navigate to `Settings` → `Addons`

**Step 4:** Paste the URL in the addon input field

**Step 5:** Click **Install** and enjoy! 🎉

### Verification

After installation, you should see **HyperStream Ultimate** appear in your addons list with a green status indicator. The addon will automatically populate content across all supported categories.
